# Material Symbols icon

`settings-rounded.svg` is Google Material Symbols Rounded, the 24 dp / default weight settings symbol.

Source: https://raw.githubusercontent.com/google/material-design-icons/6d7ca43bd6e6668531a00fcaca06d921b63dd716/symbols/web/settings/materialsymbolsrounded/settings_24px.svg

License: Apache 2.0; see `LICENSE.material-symbols.txt`. Copyright Google LLC.

`settings-rounded.png` is a transparent 96 px raster of the unchanged SVG, rendered at build time so the app does not need an SVG runtime plugin. Qt colors the alpha mask to match the selected theme.
